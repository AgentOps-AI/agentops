# SuperCompress + AgentOps

Query-aware context compression before LLM calls, with AgentOps cost/token tracing.

## Setup

```bash
pip install -r requirements.txt
export AGENTOPS_API_KEY=...
export OPENAI_API_KEY=...
# optional hosted path
export SUPERCOMPRESS_API_KEY=...
```

## Run

```bash
python supercompress_example.py
```

Docs: https://www.supercompress.dev · https://docs.agentops.ai
